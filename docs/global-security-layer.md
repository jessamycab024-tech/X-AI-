# Global-Ready Security Layer

## Core protections
- Apply security headers on every response.
- Validate and limit incoming prompt payloads.
- Enforce simple rate limiting per client IP.
- Keep secrets in environment variables only.
- Prepare for TLS termination, audit logging, and WAF integration.

## Production hardening checklist
- Use HTTPS everywhere.
- Rotate secrets and credentials regularly.
- Run dependency scanning and code audits.
- Enable backups and disaster recovery.
- Add role-based access control for admin functions.
- Support regional deployment and data residency controls.
